This project is a game called "Defeat the evil wizard"

The player chooses a character class and their name to play as.
Then the player is prompted to choose their action for the turn: Attack, Special Attack, Defensive Ability, Heal, or View Stats. (View Stats will not end turn, nor will trying to use attacks still on cooldown)
The attack power, health, and abilities are determined by class. The heal method is standard for all classes.
Special attack and defensive abilities have a cooldown that will stop the user from using them over and over.

The wizard has only an attack ability and a regenerate ability that will trigger after the user turn has ended.

To win the game, the player must attack the wizard until the wizard has no more health.
Conversely, the player loses if the character selected has no more health.
